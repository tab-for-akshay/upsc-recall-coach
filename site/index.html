    How it works

    1. Quiz: an open-weight model writes 4 MCQs for the topic; the code checks their shape before showing them.
    2. Remember: the result becomes one short memory written by code (no free text, so nobody can inject instructions) and is stored with Walrus Memory through the managed relayer, encrypted, in your learner's own namespace.
    3. Recall: next time, the coach recalls your memories and builds the plan in plain code: weakest topic first, the concepts you missed, videos for them, and the memory each line came from.
    4. Prove: Tatum's Sui RPC (gRPC) reads the MemWal account object and finds each memory's Blob object on Sui mainnet: object, transaction, size and storage epochs.

    Videos come from UPSC Tube, community-recommended sources per syllabus topic.
